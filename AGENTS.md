# Public video projects

Use one folder per project under `videos/`. Keep each project self-contained and update the root README index when adding a video. Reuse an existing project folder when appropriate.

Never include personal information, credentials, signing teams, provisioning profiles, local absolute paths, private production plans, transcripts, raw recordings or exports. Copy only reviewed source files and shareable assets; never bulk-copy a private workspace or its Git history. Strip image metadata before publishing. Never stage whole directories blindly.

Validate the project before publishing. Keep originals outside this repository unchanged. Do not add co-author attribution to commits.
