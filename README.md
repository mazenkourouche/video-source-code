# Video Source Code

Small projects built for videos. Each video has its own folder with the code, assets and instructions needed to run it.

| Video | Project | Platform |
|---|---|---|
| 01 | [Zen Flight](videos/zen-flight/) — a paper-plane game in a Japanese garden | iOS / SwiftUI / SpriteKit |

## Add a video

1. Create `videos/<project-name>/`.
2. Add its source code, shareable assets and a `README.md` explaining how to run it.
3. Add a row to the table above.

Projects are independent; there is no shared install step. Keep credentials, signing identities, private files, footage and production exports outside this repository.
